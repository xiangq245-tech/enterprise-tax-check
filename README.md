# 企业法税风险体检 V2

这是一个可直接打开的网页体验版，用于企业内部第一轮资料筛查。

## 使用
双击 index.html，完成30题，生成报告，点击“打印 / 保存为 PDF”。手机使用需将页面托管到网站。

## 已实现
- 30项自查，支持是、否、不清楚、不适用
- 企业类型记录（不据此自动计算税额）
- 事项优先级、未查明事项单列、证据清单、完整答题记录
- 桌面和手机响应布局，打印报告
- 无外部依赖、无外发填写数据、无持久化保存

## 复核规则
来自《V1律师审核修改清单》的产品要求，按事项归类而非按数量计分。优先专项复核：未入账收入、无真实交易发票、企业出资登记个人资产。个人卡收款与异常发票不直接认定违法；亲属工作、家庭车辆、公私混同等均留待事实复核。不清楚事项使报告保持暂定。所有否或不适用也不会输出“无风险”。

## 当前边界
这是独立的网页原型，尚未找到旧小程序源码，不是旧代码直接升级。未接入微信小程序、用户账户、后端、支付、收费报告解锁、律师服务预约。没有对法规全文作新的完整核验，也没有自动生成法律意见。对外收费版本应逐题由产品负责人复核，再接入真实服务与支付渠道。

## GitHub
建议仓库名 enterprise-tax-check，先设为 Private。在仓库中上传本目录所有文件，保留目录结构。持续修改需把仓库授权给 ChatGPT 的 GitHub 连接。index.html 为自包含交付文件；engine.js 为可单独验证的相同规则，修改后需要同步内嵌脚本。
